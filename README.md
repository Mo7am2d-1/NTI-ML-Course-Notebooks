# NTI ML Course Notebooks

My notebooks and exercises from the machine learning course at NTI. This is course work: practice notebooks, tasks and small example datasets. It is a learning record, not a finished project.

## What is inside

| Folder | Contents |
| --- | --- |
| `session01` | Intro notebook (AI vs ML vs DL, NumPy) |
| `session04` | Session 4 notebook (plotting, model building, linear regression) |
| `session05` | Linear regression (advertising and car data, statsmodels) and the session 5 tasks |
| `session06` | Logistic regression, SVM and GridSearch |
| `session07` | KNN and classification, plus the session 7 task |
| `session08` | Session 8 notebook (KNN and decision tree on a small dataset) |
| `session09` | AdaBoost and XGBoost |
| `session10` | A small Streamlit app that loads a saved SVM model (the model file itself is not included) |
| `session11` | Clustering (KMeans, DBSCAN) |
| `session12` | PCA and classifiers on the Iris data |
| `topic-notebooks` | Extra notebooks by topic: pandas, preprocessing, visualization, linear regression, decision trees, random forest, KNN, ensembles |
| `data` | Small CSV files used in the notebooks (course sample datasets) |

Topics are taken from the code in each notebook. Folder names follow the file names I used during the course.

## Notes

- Notebook outputs are cleared to keep the files small, so you need to run the cells to see results.
- Many notebooks read files with paths from my own computer or Google Colab (for example `/content/loan.csv`). Change the path to the matching file in `data/`.
- A few larger datasets (car details, mushrooms, Telco churn) are not included.
- Some notebooks have comments in Arabic.
- The Telco churn project is in its own repository: [Customer-Intelligence-Decision-Platform](https://github.com/Mo7am2d-1/Customer-Intelligence-Decision-Platform).

## Tools

Python, Jupyter, pandas, NumPy, scikit-learn, XGBoost, matplotlib, seaborn, statsmodels, Streamlit.
